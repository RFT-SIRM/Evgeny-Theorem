# data/raw

`SG_spectra_levels4-6.csv` is reference data from an earlier, separate stage of this research program (an independent reproduction target for a 6-connected triangular-lattice SG variant). It is **not** used by, and is **not** required to reproduce, the SU(2) theorem in this repository — the graph construction here (`src/graph/sg_graph.py`) is the standard 3-connected "tree of triangles" SG graph, a different object. It is kept here only as historical provenance for this repository's origin.
